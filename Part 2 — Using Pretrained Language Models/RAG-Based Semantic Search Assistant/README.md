# RAG-Based Semantic Search Assistant

A Python-based Retrieval-Augmented Generation (RAG) application developed to explore semantic search, text embeddings, information retrieval, and context-based answer generation.

The project demonstrates a basic RAG workflow by retrieving relevant information based on a question and providing the retrieved information as context to a language model for answer generation.

## Features

* Generate text embeddings
* Perform semantic search
* Retrieve relevant information
* Use retrieved information as context
* Generate answers using a language model
* Experiment with different questions

## Technologies Used

* Python
* Sentence Transformers
* Hugging Face Transformers
* PyTorch
* Pretrained Transformer Models
* Visual Studio Code
* Google Colab
