# LLM Response Evaluation Experiment

A Python-based experiment developed to explore language model response evaluation using a small Computer Engineering-related dataset.

The experiment compares expected answers with model-generated answers and calculates a simplified ROUGE-1 F1 score.

## Features

* Define expected and model-generated answers
* Compare text responses using word overlap
* Calculate a simplified ROUGE-1 F1 score
* Evaluate multiple responses
* Use a small Computer Engineering-related dataset
* Display evaluation results in the terminal

## Technologies Used

* Python
* Natural Language Processing
* ROUGE-1 F1
* Text Evaluation
* `collections.Counter`
* Visual Studio Code
* Google Colab
