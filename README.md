# Hands-On LLM Learning Projects

A collection of learning projects and experiments developed while studying *Hands-On Large Language Models* by Jay Alammar and Maarten Grootendorst.

The repository focuses on understanding and applying concepts related to large language models, natural language processing, tokenization, embeddings, pretrained language models, retrieval, multimodal models, fine-tuning, and language model evaluation.

The projects were developed alongside machine learning and natural language processing courses to reinforce theoretical concepts through practical experiments.

## Part 1 - Understanding Language Models

This part focuses on fundamental concepts behind large language models, including tokenization, attention mechanisms, embeddings, and Transformer-based language models.

## Part 2 - Using Pretrained Language Models

This part focuses on using pretrained language models for different natural language processing tasks, including text classification, topic analysis, retrieval-augmented generation (RAG), and multimodal language models.

## Part 3 - Training and Fine-Tuning Language Models

This part focuses on fine-tuning embedding and language models for domain-specific tasks and exploring methods for evaluating language model outputs.
